# GRIF

## Overview

GRIF is a game runner for interactive fiction games. It is designed to be a simple but extensible engine that can handle various styles of interactive fiction. Version 2 is based on the original GRIF engine and adds additional features and improvements.

GRIF is also a library that can be integrated into other applications to provide game support such as scripting, in-memoroy data storage, and save/restore functionality.

## Features

- Supports GRIF and JSON game formats
- Runs games in a terminal with a text-based interface
- Supports multiple written languages for text output
- Scripting language for game logic
- In-memory data storage for static and modified game data
- Automatic save and load functionality with a top-level overlay
- Allows for game modifications through separate files
- Runs on Windows, Linux, and macOS

## Improvements

- Can return interleaved results including media paths
- Can handle system events such as sleep
- Can stack multiple GRIF files for modular game design
